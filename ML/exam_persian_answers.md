## سؤال ۱

**(الف)** `2x⁴ − 5x³ + 4x² − 5x + 2` — چندجمله‌ای پالیندرومیک (ضرایب متقارن).

برای `x ≠ 0`، تقسیم بر `x²`:
```
2x² − 5x + 4 − 5/x + 2/x² = 2(x² + 1/x²) − 5(x + 1/x) + 4
```
جایگذاری `u = x + 1/x`، پس `x² + 1/x² = u² − 2`:
```
= 2(u² − 2) − 5u + 4 = 2u² − 4 − 5u + 4 = 2u² − 5u = u(2u − 5)
```
پس عبارت اصلی:
```
x² · u · (2u − 5) = x²(x + 1/x)(2(x + 1/x) − 5)
= x(x² + 1)(2x + 2/x − 5) = x(x² + 1) · (2x² − 5x + 2)/x
= (x² + 1)(2x² − 5x + 2) = (x² + 1)(2x − 1)(x − 2)
```

**پاسخ:** `(x² + 1)(2x − 1)(x − 2)`

بررسی: `(x²+1)(2x²−5x+2) = 2x⁴−5x³+2x²+2x²−5x+2 = 2x⁴−5x³+4x²−5x+2` ✓

**(ب)** `a⁵ + a⁴b − ab⁴ − b⁵`
```
= a⁴(a + b) − b⁴(a + b) = (a + b)(a⁴ − b⁴)
= (a + b)(a² − b²)(a² + b²) = (a + b)(a − b)(a + b)(a² + b²)
= (a + b)²(a − b)(a² + b²)
```

**پاسخ:** `(a + b)²(a − b)(a² + b²)`

**(ج)** `x⁷ + x² + 1`

روش: جدا کردن `x² + x + 1` به‌عنوان عامل مشترک:
```
x⁷ + x² + 1 = x⁷ − x + x + x² + 1
= x(x⁶ − 1) + (x² + x + 1)
= x(x³ − 1)(x³ + 1) + (x² + x + 1)
= x(x − 1)(x² + x + 1)(x + 1)(x² − x + 1) + (x² + x + 1)
= (x² + x + 1)[x(x − 1)(x + 1)(x² − x + 1) + 1]
```
محاسبهٔ داخل کروشه:
```
x(x² − 1)(x² − x + 1) = x(x⁴ − x³ + x² − x² + x − 1) = x(x⁴ − x³ + x − 1)
= x⁵ − x⁴ + x² − x
```
پس: `(x² + x + 1)(x⁵ − x⁴ + x² − x + 1)`

بررسی ضرایب:
```
(x² + x + 1)(x⁵ − x⁴ + x² − x + 1)
= x⁷ − x⁶ + x⁴ − x³ + x² + x⁶ − x⁵ + x³ − x² + x + x⁵ − x⁴ + x² − x + 1
= x⁷ + (−x⁶+x⁶) + (−x⁵+x⁵) + (x⁴−x⁴) + (−x³+x³) + (x²−x²+x²) + (x−x) + 1
= x⁷ + x² + 1 ✓
```

**پاسخ:** `(x² + x + 1)(x⁵ − x⁴ + x² − x + 1)`

## سؤال ۲

**(الف)** جایگذاری `u = x² + 1` (توجه: `u ≥ 1`):
```
u² − 5u + 6 = 0 → (u − 2)(u − 3) = 0 → u = 2 یا u = 3
```
- `x² + 1 = 2 → x² = 1 → x = ±1`
- `x² + 1 = 3 → x² = 2 → x = ±√2`

**پاسخ:** `x ∈ {−√2, −1, 1, √2}`

**(ب)** جایگذاری `u = x² ≥ 0`:
```
u² + ku + 4 = 0
```
برای نداشتن ریشه حقیقی `x`، یا معادلهٔ درجه ۲ در `u` ریشه حقیقی ندارد، یا هر دو ریشه‌اش منفی هستند.

**حالت ۱: `Δ < 0`** (ریشه حقیقی در `u` وجود ندارد):
```
k² − 16 < 0 → |k| < 4 → −4 < k < 4
```

**حالت ۲: `Δ ≥ 0` و هر دو ریشه منفی:**
- `Δ ≥ 0 → |k| ≥ 4`
- حاصل‌ضرب ریشه‌ها = `4 > 0` (هم‌علامت)
- مجموع ریشه‌ها = `−k < 0 → k > 0`
- پس `k ≥ 4`

**اجتماع حالت‌ها:** `−4 < k < 4` یا `k ≥ 4`، یعنی `k > −4`.

بررسی:
- `k = 0`: `u² + 4 = 0` → ریشه حقیقی ندارد ✓
- `k = 5`: `u² + 5u + 4 = (u+1)(u+4) = 0` → `u = −1, −4` (هر دو منفی، نامربوط به `x`) ✓
- `k = −4`: `u² − 4u + 4 = (u−2)² = 0` → `u = 2` → `x = ±√2` (ریشه دارد) ✗
- `k = −5`: `u² − 5u + 4 = (u−1)(u−4) = 0` → `u = 1, 4` (ریشه دارد) ✗

**پاسخ:** `k ∈ (−4, ∞)`

## سؤال ۴

**(الف)** `|x − 2| + |x + 3| ≤ 2x + 6`

ابتدا باید `2x + 6 ≥ 0` یعنی `x ≥ −3`.

نقاط بحرانی: `x = −3` و `x = 2`.

**بازهٔ ۱: `−3 ≤ x < 2`**
```
(2 − x) + (x + 3) ≤ 2x + 6 → 5 ≤ 2x + 6 → x ≥ −1/2
```
پس: `−1/2 ≤ x < 2`

**بازهٔ ۲: `x ≥ 2`**
```
(x − 2) + (x + 3) ≤ 2x + 6 → 2x + 1 ≤ 2x + 6 → 1 ≤ 6 ✓ (همیشه برقرار)
```
پس: `x ≥ 2`

**پاسخ:** `x ∈ [−1/2, ∞)`

**(ب)** `|x² − 2x − 3| ≤ 3`

```
−3 ≤ x² − 2x − 3 ≤ 3
```

**بخش پایین:** `x² − 2x − 3 ≥ −3`:
```
x² − 2x ≥ 0 → x(x − 2) ≥ 0 → x ≤ 0 یا x ≥ 2
```

**بخش بالا:** `x² − 2x − 3 ≤ 3`:
```
x² − 2x − 6 ≤ 0 → x = (2 ± √(4+24))/2 = (2 ± √28)/2 = 1 ± √7
→ 1 − √7 ≤ x ≤ 1 + √7
```

**اشتراک:**
```
[1 − √7, 0] ∪ [2, 1 + √7]
```

**پاسخ:** `x ∈ [1 − √7, 0] ∪ [2, 1 + √7]`

## سؤال ۵

**(الف)** `x⁵ − 3x⁴ − x³ + 3x² > 0`

تجزیه:
```
= x²(x³ − 3x² − x + 3) = x²[x²(x − 3) − (x − 3)] = x²(x − 3)(x² − 1)
= x²(x − 3)(x − 1)(x + 1)
```

نقاط بحرانی: `x = −1, 0, 1, 3` (در `x = 0` علامت تغییر نمی‌کند چون `x²` همواره `≥ 0`)

| بازه | `x²` | `x+1` | `x−1` | `x−3` | حاصل | |
|---|---|---|---|---|---|---|
| `(−∞,−1)` | `+` | `−` | `−` | `−` | `−` | |
| `(−1,0)` | `+` | `+` | `−` | `−` | `+` | ✓ |
| `(0,1)` | `+` | `+` | `−` | `−` | `+` | ✓ |
| `(1,3)` | `+` | `+` | `+` | `−` | `−` | |
| `(3,∞)` | `+` | `+` | `+` | `+` | `+` | ✓ |

در `x = 0`: عبارت = `0` (مستثنی چون `> 0` خواسته شده).

**پاسخ:** `x ∈ (−1, 0) ∪ (0, 1) ∪ (3, ∞)`

**(ب)** `(x² − 9)/(x + 2) ≤ 0` و `|x| < 5`

تجزیه: `(x − 3)(x + 3) / (x + 2) ≤ 0`

نقاط بحرانی: `x = −3` (صفر صورت)، `x = −2` (صفر مخرج، مستثنی)، `x = 3` (صفر صورت)

| بازه | `x+3` | `x−3` | `x+2` | خارج‌قسمت | |
|---|---|---|---|---|---|
| `(−∞,−3)` | `−` | `−` | `−` | `−` | ✓ |
| `(−3,−2)` | `+` | `−` | `−` | `+` | |
| `(−2,3)` | `+` | `−` | `+` | `−` | ✓ |
| `(3,∞)` | `+` | `+` | `+` | `+` | |

با احتساب `x = ±3` (صفر صورت، `≤`) و عدم احتساب `x = −2`:
```
x ∈ (−∞, −3] ∪ (−2, 3]
```

اشتراک با `|x| < 5` یعنی `(−5, 5)`:
```
x ∈ (−5, −3] ∪ (−2, 3]
```

## سؤال ۶

**(الف)** دامنه: مخرج `x² + 1 > 0` همواره. **دامنه: `ℝ`**

برد: `y = (2x − 1)/(x² + 1)`، حل برای `x`:
```
y(x² + 1) = 2x − 1 → yx² − 2x + y + 1 = 0
```
برای وجود `x` حقیقی: `Δ ≥ 0`:
```
Δ = 4 − 4y(y + 1) = 4 − 4y² − 4y = 4(1 − y − y²) ≥ 0
→ y² + y − 1 ≤ 0 → y = (−1 ± √5)/2
```
**برد:** `[(−1 − √5)/2, (−1 + √5)/2]`

**(ب)** `(f ∘ g)(x) = f(2x + 1) = (2(2x + 1) − 1) / ((2x + 1)² + 1) = (4x + 1) / (4x² + 4x + 2)`

مخرج: `4x² + 4x + 2 = 4(x + 1/2)² + 1 > 0` همیشه.

**دامنه: `ℝ`**

**(ج)** `f(−x) = (2(−x) − 1) / ((−x)² + 1) = (−2x − 1) / (x² + 1) = −(2x + 1) / (x² + 1)`

`−f(x) = −(2x − 1) / (x² + 1) = (1 − 2x) / (x² + 1)`

چون `f(−x) = −(2x + 1)/(x² + 1) ≠ (1 − 2x)/(x² + 1) = −f(x)` و `f(−x) ≠ f(x)`:

**نه زوج و نه فرد.**

## سؤال ۸

**(الف)** `f(x) = (2x + 5)/(x − 3)`

وارون:
```
y = (2x + 5)/(x − 3)
x = (2y + 5)/(y − 3)
x(y − 3) = 2y + 5
xy − 3x = 2y + 5
y(x − 2) = 3x + 5
y = (3x + 5)/(x − 2)
```

`f⁻¹(x) = (3x + 5)/(x − 2)`، دامنه: `x ≠ 2`.

بررسی یک‌به‌یک بودن: اگر `f(a) = f(b)`:
```
(2a + 5)/(a − 3) = (2b + 5)/(b − 3)
(2a + 5)(b − 3) = (2b + 5)(a − 3)
2ab − 6a + 5b − 15 = 2ab − 6b + 5a − 15
−6a + 5b = −6b + 5a
−11a = −11b → a = b ✓
```

**(ب)** `h(x) = x / (x² + 4)`

```
h'(x) = (1·(x² + 4) − x·2x) / (x² + 4)² = (4 − x²) / (x² + 4)²
```

نقاط بحرانی: `x = ±2`

- `h' > 0` وقتی `4 − x² > 0` یعنی `−2 < x < 2` → **افزایشی روی `(−2, 2)`**
- `h' < 0` وقتی `|x| > 2` → **کاهشی روی `(−∞, −2)` و `(2, ∞)`**

`h` روی کل `ℝ` وارون‌پذیر نیست: مثلاً `h(0) = 0` و `h(x) → 0` هنگامی که `x → ±∞`، پس مقادیر مکرر وجود دارد.

محدودسازی: روی `[−2, 2]` تابع `h` صرفاً افزایشی است → وارون‌پذیر. (همچنین `[2, ∞)` یا `(−∞, −2]` نیز مجازند.)

## سؤال ۱۰

**(الف)** `(A ∩ B) ∪ (A ∩ Bᶜ) ∪ (Aᶜ ∩ B)`

ابتدا دو عبارت اول را ترکیب می‌کنیم:
```
(A ∩ B) ∪ (A ∩ Bᶜ) = A ∩ (B ∪ Bᶜ) = A ∩ U = A
```
*(قانون توزیع‌پذیری → قانون متمم → قانون عضو نما)*

حالا:
```
A ∪ (Aᶜ ∩ B) = (A ∪ Aᶜ) ∩ (A ∪ B) = U ∩ (A ∪ B) = A ∪ B
```
*(قانون توزیع‌پذیری → قانون متمم → قانون عضو نما)*

**پاسخ:** `A ∪ B`

**(ب)** `(A ∪ B) ∩ (Aᶜ ∪ B)`

با استفاده از قانون توزیع‌پذیری (فاکتورگیری `B`):
```
(A ∪ B) ∩ (Aᶜ ∪ B) = (A ∩ Aᶜ) ∪ B = ∅ ∪ B = B
```
*(قانون توزیع‌پذیری → قانون متمم → قانون عضو نما)*

**پاسخ:** `B` ∎

**(ج)** `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` طبق قانون توزیع‌پذیری. پس:

`A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`

و `(A ∩ B) ∪ C` را می‌توان نوشت `(A ∩ B) ∪ C`.

برای برقراری `(A ∩ B) ∪ C = (A ∩ B) ∪ (A ∩ C)`، باید `C = A ∩ C`، یعنی `C ⊆ A`.

**شرط لازم و کافی:** `C ⊆ A`.

**اثبات (⇐):** اگر `C ⊆ A`، آنگاه `A ∩ C = C`، پس `(A ∩ B) ∪ (A ∩ C) = (A ∩ B) ∪ C`. ✓

**اثبات (⇒):** فرض کنید `(A ∩ B) ∪ C = (A ∩ B) ∪ (A ∩ C)`. هر عضو `C` در سمت چپ (و بنابراین در سمت راست) هست. اگر `x ∈ C` و `x ∈ (A ∩ B)` آنگاه `x ∈ A`. اگر `x ∈ C` و `x ∈ (A ∩ C)` آنگاه `x ∈ A`. در هر حالت `x ∈ A`. پس `C ⊆ A`. ✓

**مثال نقض وقتی `C ⊈ A`:** `A = {1}`، `B = ∅`، `C = {2}`. سمت چپ: `∅ ∪ {2} = {2}`. سمت راست: `∅ ∪ ({1} ∩ {2}) = ∅`. برابر نیستند. ✓

## سؤال ۱۱ (تشویقی)

معادله: `x³ − 6x² + 11x − 6 = 0`

فرم‌های ویتا برای معادلهٔ درجه سه `x³ + px² + qx + r = 0`:
- `p = −6`، `q = 11`، `r = −6`
- `α + β + γ = −p = 6`
- `αβ + αγ + βγ = q = 11`
- `αβγ = −r = 6`

**(الف)** `α² + β² + γ²`:
```
α² + β² + γ² = (α + β + γ)² − 2(αβ + αγ + βγ) = 6² − 2(11) = 36 − 22 = 14
```

**پاسخ:** `14`

**(ب)** `α²β + α²γ + β²α + β²γ + γ²α + γ²β`:

این عبارت برابر است با:
```
(α + β + γ)(αβ + αγ + βγ) − 3αβγ
```

اثبات: `(α + β + γ)(αβ + αγ + βγ) = α²β + α²γ + αβγ + αβ² + β²γ + αβγ + αβγ + βγ² + αγ²`
`= (α²β + α²γ + β²α + β²γ + γ²α + γ²β) + 3αβγ`

پس:
```
α²β + α²γ + β²α + β²γ + γ²α + γ²β = (6)(11) − 3(6) = 66 − 18 = 48
```

**پاسخ:** `48`

**(ج)** `α³ + β³ + γ³`:

فرمول نیوتون برای مجموع توان‌های سوم:
```
α³ + β³ + γ³ = (α + β + γ)³ − 3(α + β + γ)(αβ + αγ + βγ) + 3αβγ
= 6³ − 3(6)(11) + 3(6) = 216 − 198 + 18 = 36
```

**پاسخ:** `36`

بررسی: ریشه‌ها `1, 2, 3` هستند.
- `1 + 2 + 3 = 6` ✓
- `1·2 + 1·3 + 2·3 = 2 + 3 + 6 = 11` ✓
- `1·2·3 = 6` ✓
- `1² + 2² + 3² = 1 + 4 + 9 = 14` ✓
- `1³ + 2³ + 3³ = 1 + 8 + 27 = 36` ✓
- `1²·2 + 1²·3 + 2²·1 + 2²·3 + 3²·1 + 3²·2 = 2 + 3 + 4 + 12 + 9 + 18 = 48` ✓
