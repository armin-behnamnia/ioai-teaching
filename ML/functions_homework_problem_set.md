## Section A — Conceptual & Intuitive Questions

1. A student says: *"`y² = x` is a function because for every `x` I put in, I can find `y`."* Explain why this is incorrect. What is the precise requirement that `y² = x` fails?

   (a) What corresponds to the **domain**?
   (b) What corresponds to the **range**?
   (c) What corresponds to the **codomain**?
   (d) Why is it acceptable for two different buttons to give the same product, but not acceptable for one button to give different products on different presses?

3. Explain in your own words why `f(x − h)` shifts the graph **right** by `h`, even though the sign looks "negative." Use a specific example with `f(x) = x²` and `h = 2` to illustrate.

4. A function `f` has domain `[1, 5]` and range `[2, 8]`. Your classmate claims that `g(x) = f(2x)` has domain `[2, 10]`. Explain why this is wrong and find the correct domain.

5. Two students are debating whether `f(x) = x⁴` is "the same function" as `g(x) = x²`.
   (a) Are their graphs the same? Explain.
   (b) Are their domains the same?
   (c) Are their ranges the same?
   (d) In what sense are they related (if at all)?

6. Consider the function `f(x) = ⌊x⌋` (floor function).
   (a) Is `f` a function? Why or why not?
   (b) Does `f` have an inverse? Explain.
   (c) Is `f` increasing, decreasing, or neither?
   (d) Describe what the graph of `y = {x} = x − ⌊x⌋` looks like. What is its period?

7. Explain why a **constant function** (e.g., `f(x) = 5`) is always an even function but never an odd function (unless the constant is 0).

8. A student finds the inverse of `f(x) = (x − 3)²` by writing `f⁻¹(x) = √x + 3`. Explain what is wrong with this answer. What additional information or restriction is needed?

9. The function `f(x) = 1/x` is decreasing on `(−∞, 0)` and also decreasing on `(0, ∞)`. Is it decreasing on all of `ℝ \ {0}`? Explain why or why not with a specific counterexample.

10. Suppose `f` is an odd function and `g` is an even function. Is `f ∘ g` even, odd, or neither? Prove your answer algebraically. What about `g ∘ f`? What about `f · g`?

| 165 | Set `y=0`: `(f(x)−1)f(0) = x`. If `f(0)≠0`: `f(x) = 1+x/f(0)`. Let `c=f(0)`: `f(x) = 1+x/c`. Check: need `c=1`. **`f(x) = x+1`** |
| 166 | Set `x=0`: `f(f(y)) = f(0)+y` → `f` bijective. Set `y=0`: `f(x+f(0)) = f(x)` → periodic. Periodic bijection → `f(0)=0`. Then `f(f(y))=y` (involution) and substituting `y=f(z)`: `f(x+z) = f(x)+f(z)` (Cauchy). **`f(x) = x` or `f(x) = −x`** |
| 167 | Same as 166 after simplification. **`f(x) = x` or `f(x) = −x`** |
| 168 | Cauchy over ℚ: `f(x) = cx`. `f(f(x)) = c²x = x → c = ±1`. **`f(x) = x` or `f(x) = −x`** |
| 169 | `|f(x)−f(y)| = |x−y|` (isometry). Set `y=0`: `|f(x)−f(0)| = |x|` → `f(x) = f(0)±x`. Sign must be globally consistent. **`f(x) = x+c` or `f(x) = −x+c`** |
| 170 | Cauchy + multiplicative: `f(x) = cx`, `c = c²` → `c = 0` or `c = 1`. **`f(x) = 0` or `f(x) = x`** |
| 171 | Set `x=0`: `f(f(y)) = f(0)²+y` → bijective. Set `y=0`: `f(x²+f(0)) = f(x)²`. Let `c=f(0)`, `c=0`. Then `f(f(y))=y` and `f(x²)=f(x)²`. Try `f(x)=x`: ✓. Try `f(x)=−x`: `f(x²+f(y)) = f(x²−y) = −x²+y`, `f(x)²+y = x²+y`. Need `−x²=x²` ✗. **`f(x) = x`** |
| 172 | Partition ℝ into triples `{a,b,c}`, define `f(a)=b, f(b)=c, f(c)=a`. Then `f(f(f(x)))=x` but `f(f(a))=c ≠ a`. ∎ |
| 173 | `m(x+y) ≤ mx+my → 0 ≤ 0`. Always true. **All values of `m`** |
| 174 | If `f` continuous, it's monotonic. If increasing: `f(f(x))` increasing but `−x` decreasing — contradiction. If decreasing: `f(f(x))` increasing — again contradiction. **No continuous solution exists.** |
| 175 | Suppose `f(a) > a`. Since `f` increasing: `f(f(a)) > f(a) > a`. But `f(f(a)) = a`. Contradiction. Similarly `f(a) < a` fails. So `f(x) = x`. A non-trivial involution can't be increasing, so must be decreasing. ∎ |

## Quick Reference: Key Formulas & Techniques

| Concept | Formula / Rule |
|---|---|
| Function definition | Each input → exactly one output |
| Vertical line test | No vertical line hits graph twice |
| Domain restrictions | `1/g(x)`: `g(x)≠0`; `√g(x)`: `g(x)≥0` |
| Composition | `(f∘g)(x) = f(g(x))` — apply `g` first |
| Domain of `f∘g` | `x ∈ dom(g)` AND `g(x) ∈ dom(f)` |
| Even function | `f(−x) = f(x)` |
| Odd function | `f(−x) = −f(x)` |
| Even-odd decomposition | `f_e = [f(x)+f(−x)]/2`, `f_o = [f(x)−f(−x)]/2` |
| Inverse function | `f⁻¹(f(x)) = x`; reflect over `y = x` |
| One-to-one test | Horizontal line test / `f(a)=f(b) ⟹ a=b` |
| Translation | `f(x−h)+k`: right `h`, up `k` |
| Reflection | `−f(x)`: over x-axis; `f(−x)`: over y-axis |
| Stretch | `af(x)`: vertical by `a`; `f(bx)`: horizontal by `1/b` |
| Monotonic ⟹ one-to-one | Strictly increasing/decreasing → injective |
| Cauchy equation | `f(x+y) = f(x)+f(y)` → `f(x) = cx` (if continuous) |
| Substitution strategy | In functional equations, try `x=0, y=0, y=x, y=−x, y=1/x` |
