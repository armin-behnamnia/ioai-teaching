# Hard Factorization Problems

A curated problem set covering advanced factoring techniques: grouping, substitution, difference of squares disguised, sum/difference of cubes, factoring over surds, and multi-step problems.

## 12. Vieta's Formulas — Sum & Product of Roots

| Expression | Formula |
|---|---|
| Sum of roots | `α + β = −b/a` |
| Product of roots | `αβ = c/a` |
| `α² + β²` | `(α + β)² − 2αβ = (b/a)² − 2(c/a)` |
| `α³ + β³` | `(α + β)³ − 3αβ(α + β)` |
| `1/α + 1/β` | `(α + β)/(αβ) = −b/c` |
| `α²β + αβ²` | `αβ(α + β) = −bc/a²` |
| `(α − β)²` | `(α + β)² − 4αβ` |

## 16. Sign of Roots — Intervals Where Roots Lie

**Key idea:** For `ax² + bx + c = 0` with `a > 0`, roots `α ≤ β`, and `D = b² − 4ac ≥ 0`:

| Condition | Test |
|---|---|
| Both roots positive | `α + β > 0` and `αβ > 0` → `−b/a > 0` and `c/a > 0` |
| Both roots negative | `α + β < 0` and `αβ > 0` → `−b/a < 0` and `c/a > 0` |
| Roots of opposite sign | `αβ < 0` → `c/a < 0` |
| Both roots greater than `k` | `D ≥ 0`, `a·f(k) > 0`, `α + β > 2k` → `−b/a > 2k` |
| Both roots less than `k` | `D ≥ 0`, `a·f(k) > 0`, `α + β < 2k` |
| `k` lies between the roots | `a·f(k) < 0` |
| Exactly one root in `(k₁, k₂)` | `a·f(k₁) · a·f(k₂) < 0` |

## Quick Reference: Technique Decision Guide

| If you see... | Try... |
|---|---|
| Four terms, no common factor | Group in pairs |
| `(…)(…)(…)(…) ± constant` | Pair to form `u² + bu + c` pattern |
| `x⁴ + k` (k positive, small) | Add/subtract `2bx²` to make `A² − B²` |
| `x⁴ + bx² + c` | Treat as quadratic in `x²`, or add/sub to make difference of squares |
| `a⁴ + 4b⁴` | Sophie Germain identity |
| `a³ ± b³` | Sum/difference of cubes formula |
| `a³ + b³ + c³ − 3abc` | Use the three-variable identity |
| Higher degree with integer coefficients | Rational Root Theorem + polynomial division |
| Expression symmetric in multiple variables | Look for `a ± b`, `a − b`, etc. as factors |
| Sum/product of roots given | Vieta's: `α + β = −b/a`, `αβ = c/a` |
| Power sum `αⁿ + βⁿ` | Use recurrence `S(n) = (α+β)S(n−1) − αβ·S(n−2)` |
| Roots of unity | Exploit `αⁿ = 1` to reduce exponents mod `n` |
| Common root of two quadratics | Subtract equations, or use resultant |
| Root location (both > k, between roots, etc.) | Sign of `f(k)`, `D ≥ 0`, and Vieta conditions |
| New quadratic from transformed roots | Compute new sum and product, write `x² − Sx + P = 0` |
