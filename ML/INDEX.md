## Quick Reference

### Timeline at a Glance

```
Phase 1 (W1–8):   Foundations          2 sessions/wk   ← Linear models, GD, probability, info theory
Phase 2 (W9–20):  Core ML              4 sessions/wk   ← Classification, NNs, training, generalization
Phase 3 (W21–24): Exam Prep            4 sessions/wk   ← Review + mock exams
       >>> NATIONAL QUALIFICATION EXAM <<< (approx. Month 5–6)
Phase 4 (W25–36): Advanced ML          4 sessions/wk   ← CNNs, Transformers, generative models, RL, RLHF
Phase 5 (W37–44): IOAI Prep            4 sessions/wk   ← Past IOAI problems, mock exams, competition strategy
```

### Exam-Critical Topics (must be solid by Week 21)

1. Linear regression (OLS, ridge, GD)
2. Logistic regression (binary + softmax)
3. Gradient descent, SGD
4. MLE / MAP
5. Bias-variance tradeoff
6. Overfitting, regularization (L1, L2)
7. Cross-validation, evaluation metrics
8. k-NN
9. Decision trees, random forests
10. SVM (linear, kernels, soft margin)
11. Neural networks (MLP, forward, backprop)
12. Training: optimizers, initialization, dropout
13. k-means, GMM/EM
14. PCA
15. Information theory: entropy, KL, cross-entropy

## Notes

- This is a **living document set**. Update as the course evolves.
- Student feedback from Week 1 should inform pacing — if the class is overall weaker than expected, spend more time on Phase 1 fundamentals.
- If the national exam date shifts, adjust Phase 3 timing accordingly. The critical constraint is: all exam-critical topics must be covered before the exam.
- For the heterogeneous class: always prepare the ★ advanced sections. It's better to have them and not need them than to lose the sharp students.
