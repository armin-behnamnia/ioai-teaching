## سوال ۳: به پرسش‌های زیر پاسخ دهید

۹۱. اگر `α` و `β` ریشه‌های `x² − 7x + 10 = 0` باشند، مقدار `α² + β²` را بیابید.

۹۲. اگر `α` و `β` ریشه‌های `2x² + 5x − 3 = 0` باشند، مقدار `1/α + 1/β` را بیابید.

۹۳. اگر `α` و `β` ریشه‌های `x² + 3x − 5 = 0` باشند، مقدار `α³ + β³` را بیابید.

۹۴. اگر `α` و `β` ریشه‌های `x² − 6x + 4 = 0` باشند، مقدار `(α − β)²` را بیابید.

۹۵. اگر `α` و `β` ریشه‌های `3x² − 2x − 7 = 0` باشند، مقدار `α²β + αβ²` را بیابید.

۹۶. اگر `α` و `β` ریشه‌های `x² + px + q = 0` باشند، `α⁵ + β⁵` را بر حسب `p` و `q` بیابید.

۹۷. اگر `α` و `β` ریشه‌های `x² + 7x + 1 = 0` باشند، مقدار `α/β + β/α` را بیابید.

۹۸. اگر `α` و `β` ریشه‌های `x² − x − 1 = 0` باشند، مقدار `α³ + β³` را بیابید و نشان دهید برابر `2α + 2β + 3` است.

۹۹. معادله‌ای با ضرایب صحیح بیابید که `3 + √7` یکی از ریشه‌های آن باشد.

۱۰۰. معادله‌ای با ضرایب صحیح بیابید که `√5 − √3` یکی از ریشه‌های آن باشد.

۱۰۱. ریشه‌های `x² − 3x + k = 0` برابر `α` و `β` هستند. `k` را طوری بیابید که `α − β = 5`.

۱۰۲. ریشه‌های `x² + px + 12 = 0` اختلافشان ۱ است. همه مقادیر ممکن `p` را بیابید.

۱۰۳. `k` را طوری بیابید که یکی از ریشه‌های `x² + (k+1)x + 2k = 0` دو برابر ریشه دیگر باشد.

۱۰۴. `m` را طوری بیابید که ریشه‌های `x² − mx + m + 7 = 0` برابر باشند.

۱۰۵. معادله‌ای بیابید که ریشه‌های آن `α + 1` و `β + 1` باشند، جایی که `α, β` ریشه‌های `x² − 4x + 2 = 0` هستند.

۱۰۶. معادله‌ای بیابید که ریشه‌های آن `α² + 1/β²` و `β² + 1/α²` باشند، جایی که `α, β` ریشه‌های `x² − 3x + 1 = 0` هستند.

۱۰۷. برای چه مقادیر `k`، معادله `x² + kx + 9 = 0` ریشه‌های برابر دارد؟

۱۰۸. برای چه مقادیر `k`، معادله `2x² + 3x + k = 0` دو ریشه حقیقی متمایز دارد؟

۱۰۹. برای چه مقادیر `m`، معادله `x² + (m+2)x + m + 5 = 0` ریشه حقیقی ندارد؟

۱۱۰. برای چه مقادیر `p`، معادله `(p+1)x² − 2(p−1)x + p−2 = 0` ریشه‌های برابر دارد؟

۱۱۰. برای چه مقادیر حقیقی `k`، معادله `x² + (k+1)x + k² = 0` حداقل یک ریشه حقیقی دارد؟

۱۱۲. نشان دهید که `x² + 2ax + (a² + a + 1) = 0` برای هر `a > −1` ریشه حقیقی ندارد.

۱۱۳. اگر `x² + px + q = 0` و `x² + qx + p = 0` ریشه مشترک داشته باشند، نشان دهید که `p + q + 1 = 0` یا `p = q`.

۱۱۴. اگر `x² + ax + b = 0` و `x² + bx + a = 0` ریشه مشترک داشته باشند، ریشه مشترک را بر حسب `a` و `b` بیان کنید.

۱۱۵. همه مقادیر `k` را بیابید که `x² − kx + 12 = 0` و `x² + kx + 12 = 0` ریشه مشترک دارند.

۱۱۶. برای چه مقادیر `m`، هر دو ریشه `x² − 2mx + m² − 1 = 0` بین `−2` و `4` قرار دارند؟

۱۱۷. برای چه مقادیر `m`، معادله `x² + 2mx + m² − 4 = 0` دارد:

&nbsp;&nbsp;&nbsp;&nbsp;(الف) هر دو ریشه مثبت

&nbsp;&nbsp;&nbsp;&nbsp;(ب) هر دو ریشه منفی

&nbsp;&nbsp;&nbsp;&nbsp;(ج) ریشه‌های علامت مخالف

۱۱۸. `k` را طوری بیابید که `x² − 2kx + k² − 5 = 0` داشته باشد:

&nbsp;&nbsp;&nbsp;&nbsp;(الف) هر دو ریشه بزرگتر از ۱

&nbsp;&nbsp;&nbsp;&nbsp;(ب) هر دو ریشه کوچکتر از ۳

&nbsp;&nbsp;&nbsp;&nbsp;(ج) عدد ۲ بین ریشه‌ها قرار گیرد

۱۱۹. برای چه مقادیر `a`، معادله `x² − 2ax + a² − 9 = 0` دقیقاً یک ریشه در بازه `(0, 5)` دارد؟

۱۲۰. برای چه مقادیر `m`، هر دو ریشه `x² + mx + 4 = 0` حقیقی و در بازه `(−1, 3)` هستند؟

۱۲۱. برای چه مقادیر `k`، معادله `x² + kx + 3 = 0` یک ریشه در `(0, 1)` و ریشه دیگر در `(2, 3)` دارد؟

۱۲۲. `k` را طوری بیابید که مجموع ریشه‌های `x² + (2k−1)x + k² − 3 = 0` برابر حاصل‌ضرب ریشه‌ها باشد.

۱۲۳. `p` را طوری بیابید که یکی از ریشه‌های `x² + px + 12 = 0` مربع ریشه دیگر باشد.

۱۲۴. `k` را طوری بیابید که ریشه‌های `x² + (3k−1)x + 2k² + 2k − 4 = 0` اختلافشان ۲ باشد.

۱۲۵. اگر `α, β` ریشه‌های `x² + mx + m² − 7 = 0` باشند، `m` را طوری بیابید که `α² + β² = 5`.

۱۲۶. همه `k` های حقیقی را بیابید که ریشه‌های `α, β` معادله `x² − 2kx + k² − 4 = 0` شرط `|α| + |β| = 6` را برآورده کنند.

۱۲۷. اگر `α, β` ریشه‌های `x² + px + q = 0` باشند، معادله‌ای بیابید که ریشه‌های آن `α/(α+1)` و `β/(β+1)` باشند.

۱۲۸. اگر `α, β` ریشه‌های `x² + 5x + 3 = 0` باشند، معادله‌ای بیابید که ریشه‌های آن `(α+β)²` و `(α−β)²` باشند.

۱۲۹. اگر `α, β` ریشه‌های `x² − x − 4 = 0` باشند، معادله‌ای بیابید که ریشه‌های آن `1/(α+β)` و `1/(αβ)` باشند.

۱۳۰. اگر `α, β` ریشه‌های `2x² + 3x + 5 = 0` باشند، معادله‌ای بیابید که ریشه‌های آن `α + 1/β` و `β + 1/α` باشند.

## سوالات چالشی (اختیاری)

۱۳۱. فرض کنید `α, β` ریشه‌های `x² + x + 1 = 0` باشند. مقدار `α²⁰²⁵ + β²⁰²⁵` را بیابید.

۱۳۲. فرض کنید `α, β` ریشه‌های `x² − 2017x + 1 = 0` باشند. مقدار `α²⁰¹⁷ + β²⁰¹⁷` را بر پیمانه ۱۰ بیابید.

۱۳۳. اگر `α, β` ریشه‌های `x² + x − 1 = 0` باشند، مقدار `α⁵ + β⁵` را بیابید.

۱۳۴. فرض کنید `α, β, γ` ریشه‌های `x³ − 3x² + 4x − 2 = 0` باشند. `α² + β² + γ²`، `αβ + βγ + γα` و `αβγ` را بیابید.

۱۳۵. اگر `α, β` ریشه‌های `x² + x + 1 = 0` باشند، `α¹⁰⁰ + β¹⁰⁰` و `α · β¹⁰⁰ + β · α¹⁰⁰` را محاسبه کنید.

۱۳۶. با دانستن اینکه `α` و `β` ریشه‌های `x² + 7x + 2 = 0` هستند، `⌊α⌋ + ⌊β⌋` را بیابید (`⌊·⌋` تابع کف است).

۱۳۷. اگر `α, β` ریشه‌های `x² − 6x + 4 = 0` باشند، مقدار `√α + √β` را بیابید.

۱۳۸. فرض کنید `r₁, r₂` ریشه‌های `x² + 2024x + 2025 = 0` باشند. `(r₁ + 1)(r₂ + 1)` را محاسبه کنید.

۱۳۹. اگر `α, β` ریشه‌های `x² + x + 2 = 0` باشند، `α⁸ + β⁸` را بیابید.

۱۴۰. فرض کنید `α` ریشه `x² − x − 1 = 0` باشد. `α⁴ − 3α²` را بدون محاسبه صریح `α` بیابید.

۱۴۱. فرض کنید `α, β` ریشه‌های `x² + 3x + 9 = 0` باشند. `α³ + β³` و `α⁶ + β⁶` را بیابید.

۱۴۲. اگر `α` و `β` ریشه‌های `x² − x + 1 = 0` باشند، `α²⁰²⁶ + β²⁰²⁶` را بیابید.

۱۴۳. اگر `r` ریشه `x³ − 2x² + x − 3 = 0` باشد، مقدار `r⁴ − 2r³ + r²` را بیابید.

۱۴۴. معادله `x² + bx + c = 0` ریشه‌های `α` و `β` دارد. معادله `x² + (α + β)x + αβ = 0` ریشه‌های `γ` و `δ` دارد. `γ + δ` و `γδ` را بر حسب `b` و `c` بیان کنید.

۱۴۵. فرض کنید `α, β` ریشه‌های `x² + mx + n = 0` باشند. اگر `α² + β² = 6` و `α³ + β³ = 14`، `m` و `n` را بیابید.

۱۴۶. فرض کنید `p, q` ریشه‌های `x² + x + 1 = 0` باشند. `p³ + q³` و `p⁶ + q⁶` را محاسبه کنید. توضیح دهید چرا دومی برابر ۲ است.

۱۴۷. اگر `α, β` ریشه‌های `x² + 2ax + b = 0` و `γ, δ` ریشه‌های `x² + 2ax + c = 0` باشند (با `a² > b > c`)، شرط روی `a, b, c` را بیابید تا چهار ریشه به ترتیب مرتب شده تشکیل دنباله حسابی بدهند.

۱۴۸. اگر `α, β` ریشه‌های `x² + bx + c = 0` و `β, γ` ریشه‌های `x² + cx + b = 0` با `α ≠ β` باشند، `α + γ` را بر حسب `b` و `c` بیابید.

۱۴۹. با دانستن اینکه `α, β` ریشه‌های `x² + x + 1 = 0` هستند، معادله‌ای بیابید که ریشه‌های آن `α²⁰²⁴` و `β²⁰۲۴` باشند.

۱۵۰. فرض کنید `α, β` ریشه‌های `x² + (k² − 4)x + k = 0` باشند. برای چه مقادیر `k` ریشه‌ها مختلط (غیرحقیقی) هستند؟

۱۵۱. معادله `x² + bx + c = 0` ریشه‌های `α, β` دارد. با دانستن `|α| + |β| = 5` و `αβ = −6`، `b` را بیابید.

۱۵۲. فرض کنید `α, β` ریشه‌های `x² + x − 3 = 0` باشند. `α⁷ + β⁷` را محاسبه کنید.
