## سؤال ۱ (۸ نمره)

**الف) (۳ نمره)**
- $X = \mathbb{R}^3$ (تعداد مشتریان $\in \mathbb{R}^+$، روز هفته $\in \{1,...,7\}$، کد آب‌وهوا $\in \mathbb{R}$)
- $Y = \mathbb{R}$ (درآمد دلاری)
- نوع: با نظارت (Supervised)، رگرسیون (خروجی پیوسته)

**ب) (۳ نمره)**
$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(w_1 x_{i1} + w_2 x_{i2} + w_3 x_{i3} + b - y_i)^2$$

**ج) (۲ نمره)** بیش‌برازش (Overfitting): مدل با ۲۰۰+ پارامتر و ۳۶۵ داده، نویز را حفظ کرده نه الگوی واقعی را. خطای آزمون بالا چون مدل عمومیت (generalization) ندارد.

## سؤال ۲ (۱۲ نمره)

**الف)**
- $\bar{x} = 2.0$، $\bar{y} = 6.0$
- $\text{Var}(x) = \frac{(0-2)^2+(1-2)^2+(2-2)^2+(3-2)^2+(4-2)^2}{5} = \frac{4+1+0+1+4}{5} = 2.0$
- $\text{Cov}(x,y) = \frac{(-2)(-4)+(-1)(-3)+0+(1)(2)+(2)(6)}{5} = \frac{8+3+0+2+12}{5} = 5.0$

**ب)**
- $w^* = \text{Cov}/\text{Var} = 5/2 = 2.5$
- $b^* = \bar{y} - w^*\bar{x} = 6 - 5 = 1.0$
- مدل: $\hat{y} = 2.5x + 1$

**ج)** پیش‌بینی‌ها: $[1, 3.5, 6, 8.5, 11]$
- باقی‌مانده‌ها: $[1, -0.5, -1, -0.5, 1]$
- $SS_{\text{res}} = 1 + 0.25 + 1 + 0.25 + 1 = 3.5$
- $\text{MSE} = 3.5/5 = 0.7$
- $SS_{\text{tot}} = 16 + 9 + 1 + 4 + 36 = 66$
- $R^2 = 1 - 3.5/66 \approx 0.947$

**د)**
- $w_{\text{ridge}} = 5/(2+0.5) = 5/2.5 = 2.0$
- $|w_{\text{ridge}}|/|w^*| = 2/2.5 = 0.8$
- شیب ۲۰٪ کوچک‌تر شده → مدل محتاط‌تر، حساسیت کمتر به $x$.

## سؤال ۳ (۱۰ نمره)

**الف)** خطای آموزش با افزایش $d$ همیشه کاهش می‌یابد (یا ثابت می‌ماند). چون چندجمله‌ای درجه بالاتر می‌تواند هر تابع درجه پایین‌تر را نمایش دهد (ضرایب اضافی = صفر).

**ب)** خطای آزمون اول کاهش می‌یابد (مدل الگوی واقعی را یاد می‌گیرد) سپس افزایش می‌یابد (مدل نویز را حفظ می‌کند). این «شکاف تعمیم» (generalization gap) است.

**ج)** با افزایش $\lambda$، ضرایب کوچک‌تر می‌شوند (shrinkage). وقتی $\lambda \to \infty$، $w \to 0$ و مدل $\bar{y}$ را پیش‌بینی می‌کند (بیش‌برازش شدید / underfitting).

**د)** افزایش درجه → پیچیدگی زیاد → بیش‌برازش. افزایش $\lambda$ → پیچیدگی کم → کم‌برازش. هر دو «کنترل‌کننده پیچیدگی» هستند ولی در جهت مخالف.

## سؤال ۴ (۱۲ نمره)

**الف)** از ۱۰۰۰۰ بیمار: ۲۰۰ بیمار، ۹۸۰۰ سالم

| | پیش‌بینی بیمار | پیش‌بینی سالم |
|---|---|---|
| **بیمار واقعی** | TP = 190 | FN = 10 |
| **سالم واقعی** | FP = 392 | TN = 9408 |

- TP = 0.95 × 200 = 190
- FN = 200 - 190 = 10
- FP = 0.04 × 9800 = 392
- TN = 9800 - 392 = 9408

**ب)**
- Accuracy = (190 + 9408) / 10000 = 9598/10000 = 95.98%
- Precision = 190 / (190 + 392) = 190/582 ≈ 32.65%
- Recall = 190 / (190 + 10) = 190/200 = 95%
- F1 = 2 × (0.3265 × 0.95) / (0.3265 + 0.95) = 2 × 0.3102 / 1.2765 ≈ 48.59%

**ج)**
$$P(\text{بیمار}|\text{مثبت}) = \frac{0.95 \times 0.02}{0.95 \times 0.02 + 0.04 \times 0.98} = \frac{0.019}{0.019 + 0.0392} = \frac{0.019}{0.0582} \approx 32.65\%$$

این دقیقاً برابر با Precision است. $P(\text{بیمار}|\text{مثبت})$ = Precision. دلیل: هر دو نسبت TP به کل پیش‌بینی‌های مثبت را می‌سنجند. وقتی بیماری نادر است (۲٪)، حتی با تست خوب، اکثر مثبت‌ها کاذب هستند.

**د)**
- بیماری کشنده: گزینه الف (Recall = ۹۹٪) — از دست دادن بیمار واقعی خطرناک‌تر از هشدار کاذب است.
- غربالگری معمول: گزینه ب (Precision = ۹۹٪) — هزینه‌های بررسی‌های بعدی بالا است، هشدار کاذب باید کم باشد.

## سؤال ۵ (۱۲ نمره)

**الف) MLE برنولی**
- درست‌نمایی: $L = \prod_i \theta^{x_i}(1-\theta)^{1-x_i}$
- لگاریتم: $\ell = k\log\theta + (n-k)\log(1-\theta)$ که $k = \sum x_i$
- مشتق: $\frac{d\ell}{d\theta} = \frac{k}{\theta} - \frac{n-k}{1-\theta} = 0$
- حل: $k(1-\theta) = (n-k)\theta \Rightarrow k = n\theta \Rightarrow \hat{\theta} = k/n$

**ب) MLE توزیع توانی**
- $p(x|\theta) = \theta x^{\theta-1}$
- درست‌نمایی: $L = \prod_i \theta x_i^{\theta-1} = \theta^n \prod_i x_i^{\theta-1}$
- لگاریتم: $\ell = n\log\theta + (\theta-1)\sum_i \log x_i$
- مشتق: $\frac{d\ell}{d\theta} = \frac{n}{\theta} + \sum_i \log x_i = 0$
- حل: $\hat{\theta} = -\frac{n}{\sum_i \log x_i}$

*(بررسی: چون $0 \leq x_i \leq 1$، $\log x_i \leq 0$، پس $\hat{\theta} > 0$ ✓)*

## سؤال ۶ (۱۲ نمره)

**الف) MLE = MSE**

مدل: $y_i = wx_i + b + \epsilon_i$، $\epsilon_i \sim \mathcal{N}(0, \sigma^2)$

- درست‌نمایی: $p(\mathcal{D}|w,b) = \prod_i \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_i - wx_i - b)^2}{2\sigma^2}\right)$
- لگاریتم: $\ell = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_i (y_i - wx_i - b)^2$
- جمله اول ثابت. جمله دوم متناسب با $-n \cdot \text{MSE}$
- بیشینه‌کردن $\ell$ ≡ کمینه‌کردن MSE ✓

**ب) لاپلاسی**
- $p(\epsilon) = \frac{1}{2b}\exp(-|\epsilon|/b)$
- $\ell = n\log\frac{1}{2b} - \frac{1}{b}\sum_i |y_i - wx_i - b|$
- بیشینه‌کردن $\ell$ ≡ کمینه‌کردن $\sum_i |y_i - wx_i - b|$ = MAE ✓

**ج)** MAE را ترجیح می‌دهیم. MSE خطاهای بزرگ را توان دو می‌کند ($e^2$) و داده‌های پرت تسلط پیدا می‌کنند. MAE ($|e|$) خطی است و حساسیت کمتری به outlier دارد.

## سؤال ۷ (۸ نمره)

**الف)**
- $\nabla L(w) = L'(w) = 2(w-5)$
- به‌روزرسانی: $w \leftarrow w - \eta \cdot 2(w-5)$

**ب)** گرادیان جهت تندترین **افزایش** را نشان می‌دهد. برای کمینه‌کردن $L$ باید در جهت **مخالف** گرادیان حرکت کنیم (downhill). اگر اضافه می‌کردیم، به سمت تندترین افزایش می‌رفتیم و $L$ زیاد می‌شد.

**ج)** اغلب مدل‌ها راه‌حل تحلیلی ندارند (مثل Lasso به دلیل $|w|$ غیرقابل‌مشتق، لجستیک، شبکه عصبی). شیب نزولی یک روش تکراری است که به‌تدریج به سمت کمینه حرکت می‌کند.

## سؤال ۸ (۱۴ نمره)

**الف)** نشت داده (Data Leakage): محاسبه آمار روی کل داده قبل از تقسیم. داده آموزش اطلاعاتی از داده آزمون دارد. راه‌حل: اول تقسیم، سپس محاسبه آمار فقط روی آموزش.

**ب)** اسپم ۵٪ است (۵۰۰ از ۱۰۰۰۰). مدل «همه غیراسپم» دقت ۹۵٪ دارد. دقت ۹۶٪ فقط ۱٪ بهتر از baseline است و گمراه‌کننده است. باید Precision/Recall/F1 بررسی شود.

**ج)** $F_1 = 2 \times \frac{0.80 \times 0.60}{0.80 + 0.60} = 2 \times 0.48 / 1.40 = 0.96/1.40 \approx 0.686$

Recall = ۰٫۶۰ یعنی: از کل اسپم‌های واقعی، فقط ۶۰٪ شناسایی شده. ۴۰٪ اسپم از دست رفته.

**د)** $P(\text{اسپم}|\text{پیش‌بینی اسپم})$ = Precision. چون اسپم نادر است (۵٪)، طبقه‌بند خوب هم FP زیادی تولید می‌کند. طبقه بیز: $P(\text{اسپم}|\text{مثبت}) = \frac{P(\text{مثبت}|\text{اسپم}) \times 0.05}{P(\text{مثبت})}$. وقتی prior کوچک است، حتی likelihood خوب هم posterior متوسط می‌دهد.

**هـ)** ۵ مدل: معتبر است اگر آزمون فقط یک‌بار استفاده شود.  
۵۰۰ مدل و انتخاب بر اساس کمترین خطای **آزمون**: **نامعتبر**. این «بیش‌برازش به مجموعه آزمون» است. با ۵۰۰ امتحان، مدلی شانساً خوب عمل کرده. مجموعه آزمون باید دقیقاً یک‌بار برای ارزیابی نهایی استفاده شود.

## سؤال ۹ (۱۲ نمره)

**الف)** بله، Variance به صفر میل می‌کند. وقتی $\mathcal{D}$ بی‌نهایت بار نمونه‌گیری شود و میانگین گرفته شود، $\hat{f} \to \mathbb{E}_\mathcal{D}[\hat{f}]$ و Variance = $\mathbb{E}[(\hat{f} - \mathbb{E}[\hat{f}])^2] \to 0$. اما Bias تغییر نمی‌کند — Bias به کلاس مدل بستگی، نه به تعداد مجموعه‌ها.

**ب)**
- $\lambda = 0$ (OLS): Bias پایین (مدل آزاد برازش می‌کند)، Variance بالا (به نویز حساس)
- $\lambda \to \infty$: Bias بالا ($w \to 0$، $\hat{y} \to \bar{y}$)، Variance پایین (مدل تقریباً ثابت)

**ج)**
- خطای مورد انتظار = $4 + 9 + 1 = 14$
- داده بیشتر → Variance کاهش (همیشه)؛ Bias تا حدی کاهش (اگر مدل قادر به یادگیری الگو با داده بیشتر باشد)؛ $\sigma^2$ کاهش **نمی‌یابد** (نویز ذاتی است).

**د)**
- قبل: $4 + 9 + 1 = 14$
- بعد: $6 + 4 + 1 = 11$
- کاهش ۳ واحد. تنظیم مفید بود: افزایش Bias (۴→۶) جبران‌شده توسط کاهش Variance (۹→۴).

## سؤال ۱۰ — امتیازی (۱۵ نمره)

**الف) $\sum e_i = 0$**

$$\sum_i e_i = \sum_i (y_i - w^* x_i - b^*) = \sum_i y_i - w^* \sum_i x_i - n b^*$$

$$= n\bar{y} - w^* n \bar{x} - n(\bar{y} - w^*\bar{x}) = n\bar{y} - n w^* \bar{x} - n\bar{y} + n w^* \bar{x} = 0 \quad \checkmark$$

**ب) $\sum x_i e_i = 0$**

با جایگذاری $b^* = \bar{y} - w^*\bar{x}$:

$$e_i = y_i - w^* x_i - \bar{y} + w^*\bar{x} = (y_i - \bar{y}) - w^*(x_i - \bar{x}) = \tilde{y}_i - w^* \tilde{x}_i$$

$$\sum_i x_i e_i = \sum_i x_i(\tilde{y}_i - w^* \tilde{x}_i) = \sum_i x_i \tilde{y}_i - w^* \sum_i x_i \tilde{x}_i$$

$$\sum_i x_i \tilde{x}_i = \sum_i x_i(x_i - \bar{x}) = \sum_i x_i^2 - \bar{x}\sum_i x_i = \sum_i x_i^2 - n\bar{x}^2 = \sum_i (x_i - \bar{x})^2 = n \cdot \text{Var}(x)$$

$$\sum_i x_i \tilde{y}_i = \sum_i x_i(y_i - \bar{y}) = \sum_i x_i y_i - \bar{y}\sum_i x_i = \sum_i x_i y_i - n\bar{x}\bar{y} = \sum_i (x_i - \bar{x})(y_i - \bar{y}) = n \cdot \text{Cov}(x,y)$$

$$\sum_i x_i e_i = n \cdot \text{Cov}(x,y) - w^* \cdot n \cdot \text{Var}(x) = n\left(\text{Cov}(x,y) - \frac{\text{Cov}(x,y)}{\text{Var}(x)} \cdot \text{Var}(x)\right) = n(\text{Cov} - \text{Cov}) = 0 \quad \checkmark$$

**ج) تجزیه واریانس**

از $y = \hat{y} + e$:

$$\text{Var}(y) = \text{Var}(\hat{y} + e) = \text{Var}(\hat{y}) + \text{Var}(e) + 2\,\text{Cov}(\hat{y}, e)$$

کافی است نشان دهیم $\text{Cov}(\hat{y}, e) = 0$:

$$\text{Cov}(\hat{y}, e) = \mathbb{E}[\hat{y} \cdot e] - \mathbb{E}[\hat{y}]\mathbb{E}[e]$$

از (الف): $\mathbb{E}[e] = \frac{1}{n}\sum e_i = 0$.

$$\mathbb{E}[\hat{y} \cdot e] = \frac{1}{n}\sum_i \hat{y}_i e_i = \frac{1}{n}\sum_i (w^* x_i + b^*) e_i = \frac{w^*}{n}\sum_i x_i e_i + \frac{b^*}{n}\sum_i e_i$$

از (الف) و (ب): هر دو جمله صفر هستند. پس $\text{Cov}(\hat{y}, e) = 0$.

$$\therefore \text{Var}(y) = \text{Var}(\hat{y}) + \text{Var}(e) \quad \blacksquare$$
